# Cybersecurity Projects

A practical cybersecurity learning and portfolio repository documenting my progression from cybersecurity fundamentals to security monitoring, SIEM, incident response, threat detection, and cloud security.

## Learning Path

The repository is organised into nine stages. Each stage builds on the previous one, and projects become progressively more difficult.

```
01 → Cybersecurity Foundations
02 → Networking
03 → Linux
04 → Security Monitoring
05 → SIEM
06 → Incident Response
07 → Threat Detection
08 → Cloud Security
09 → Capstone Projects
```

Early stages cover core concepts and tooling. Middle stages move into monitoring, SIEM and incident response. Later stages cover threat detection and cloud security, and the capstones combine everything into larger investigations.

## Goal

This repository is intended to demonstrate practical cybersecurity knowledge and hands-on learning for entry-level SOC Analyst / Junior Security Analyst roles.

## Methodology

For each completed project, I document:

1. Objective
2. Scenario
3. Tools
4. Investigation
5. Evidence
6. Findings
7. Recommended actions
8. Lessons learned

## Repository Structure

Each project folder contains a `README.md` and `evidence/` and `screenshots/` folders for supporting material.

## Safety

All cybersecurity activities are performed only in authorised lab environments, CTFs, simulated environments, or systems owned or authorised by the learner. This repository contains no real credentials, malware or real-world targets.
